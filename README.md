<h1 align="center">Athena Logos</h1>

<p align="center">
  <b>Voice, chat, agents and tools for Athena-Engine.</b><br>
  Your own AI assistant, running on your machines.
</p>

Athena Logos is the face of [Athena-Engine](https://github.com/xangel82/Athena-Engine):
the app you talk to. The engine runs the models on your hardware; Athena Logos
gives them a voice, a memory, your documents and the tools to get things done.
Inside the app she is simply **Athena**.

This repository holds **only the releases**: ready-to-run executables for
Windows, macOS and Linux, plus the licence and the installation guides. The
source code is not public.

## What Athena does

- **Talks and listens.** Hands-free voice conversation in the browser, with
  natural turn-taking, or plain text chat. Several users, each with their own
  conversations, files and agents.
- **Knows your documents.** A Library for PDFs, Word files, spreadsheets,
  presentations, EPUB books, web pages, photos, audio and video: Athena reads
  them, searches them by meaning and cites where she found the answer.
  Collections keep them in order, on screen and on disk.
- **Remembers.** A memory of what matters about you, which you can read and
  edit.
- **Works for you.** Agents and reminders that run on a schedule, skills for
  recurring tasks, web search and a sandboxed mini browser, files and commands
  inside a folder you choose, with your confirmation for anything that leaves
  the machine.
- **Creates.** Canvas documents, short videos with sound generated by
  Athena-Engine, and images through your OpenAI account, if you connect it.

Everything stays on your network: Athena Logos talks to your engine, and to
other services only when you connect them (web search, email, image generation).

## Requirements

- **Athena-Engine**, reachable from the machine running Athena Logos (the same
  machine or another one on your network). See its
  [quick start](https://github.com/xangel82/Athena-Engine#quick-start).
- One of:
  - **Windows 10 or 11**, x64;
  - **macOS on Apple Silicon** (M1 or later);
  - **Linux arm64**, such as NVIDIA DGX Spark or ASUS Ascent GX10
    (tested on Ubuntu 24.04).
- A modern browser to open the app: Chrome, Edge, Safari or Firefox, on any
  device of your network, phones included.

Nothing else to install: Node.js and everything Athena needs are inside the
executable.

## Quick start

1. Unpack the archive and start the executable from a terminal
   (step-by-step guides: [Windows](docs/install-windows.md),
   [macOS](docs/install-macos.md), [Linux](docs/install-linux.md)).
   Tell it where your engine is:

   ```sh
   ATHENA_ENGINE_URL=http://192.168.1.10:30007 ./athena-logos-linux-arm64
   ```

2. The terminal prints the address (port **8080**) and, the first time, a
   **6-digit setup code**.
3. Open `https://<this computer's address>:8080` in your browser. The first
   time the browser warns about the certificate: Athena makes her own, accept it
   once.
4. Type the setup code, create the administrator account and choose **where
   Athena can work**: the folder her file and command tools stay inside (empty
   means your home folder).
5. Say hello.

The engine address, its API key and its certificate can also be set later, in
**Settings → AI engine**. Other users are added in **Settings → Users**.
The **?** at the top of the app opens the full guide, in English and Italian.

## Configuration

All optional, as environment variables:

| Variable | Default | |
|---|---|---|
| `ATHENA_ENGINE_URL` | `http://localhost:30007` | where Athena-Engine is |
| `ATHENA_API_KEY` | empty | the engine's API key, if it asks for one |
| `ATHENA_MODEL` | `Athena` | the model name on the engine |
| `ATHENA_PORT` | `8080` | the port of the app |
| `ATHENA_TLS` | `auto` | `auto`: https with its own certificate (http on the same port is redirected); `cert`: your certificate, with `ATHENA_TLS_CERT` and `ATHENA_TLS_KEY`; `http`: plain http, only behind an https proxy |
| `ATHENA_DATA_DIR` | `~/.athena-voice` | conversations, files, Library, settings |
| `ATHENA_WORKSPACE_ROOT` | the choice made at first start, or your home | the folder Athena's tools stay inside; when set, it wins |
| `ATHENA_SEARCH_URL` | off | web search: a SearXNG instance with JSON output |
| `ATHENA_BROWSER` | `auto` | the browser the mini browser drives: `auto`, `edge`, `chrome`, `firefox`, a path, or `off` |

If the engine uses https with its own certificate (for example Caddy with
`tls internal`), put its root certificate in the data folder as
`engine-ca.pem`.

## Updating and removing

- **Update:** stop Athena, replace the executable with the new one, start it
  again. Your data stays in the data folder.
- **Remove:** delete the executable and, if you want to erase everything, the
  data folder (`~/.athena-voice`, or `ATHENA_DATA_DIR`).
